A one-line office joke for make.fun's "Make the AI Judge Laugh: the Office Joke Open" bounty: the classic complaint about a meeting that could have been an email, with the twist landing in the last few words — the manager emails the minutes, then books a meeting to discuss the email. The program writes the joke (one line, 131 characters) to `entry.txt`, validating the gate (1–200 characters, single line, office detail) before writing.

## Run it

```sh
node main.ts
```

`main.ts` writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Node 22+, standard library only, no network, fully deterministic.
